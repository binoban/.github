# Contributing to Binoban

- Report bugs or suggest improvements in the relevant repository's issues.
- Keep pull requests focused on one problem and target the default branch.
- Follow the repository's setup instructions and coding style.
- Run relevant checks and describe the results. If a check was not run, explain why.
- Update documentation or examples when behavior changes.
- Remove credentials, customer data, and private deployment details from changes and reports.

Follow any repository-specific contribution guide and our [Code of Conduct](https://github.com/binoban/.github/blob/main/CODE_OF_CONDUCT.md).

Questions: [tech@binoban.io](mailto:tech@binoban.io).
Report vulnerabilities privately using the [security policy](https://github.com/binoban/.github/blob/main/SECURITY.md).
