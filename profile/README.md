# Binoban

**Build on customer data. Act with foresight.**

Binoban provides enterprise Customer Data Experience Platform (CDXP) infrastructure that connects customer data with prediction, decisioning, and activation.

Built for organizations that need control over first-party data, Binoban brings together identity resolution, customer profiles, audience segmentation, customer engagement, retail media, and ad exchange.

This GitHub organization hosts Binoban's public SDK integration packages and reference apps. Explore how to connect your websites and mobile applications to a Binoban deployment, then follow the developer guides to build your integration.

[Developer Quick Start](https://docs.binoban.io/developers/quickstart) · [Documentation](https://docs.binoban.io) · [Website](https://binoban.io)

## Start building with Binoban

- **Send your first event.** Follow the [Developer Quick Start](https://docs.binoban.io/developers/quickstart) for source setup, credentials, and your first tracking request.
- **Connect customer data.** Track events and identify users across websites, apps, and backends with the [customer data tracking guides](https://docs.binoban.io/developers/track-customer-data).
- **Integrate customer engagement.** Set up app and web push with the [Binoban Engage guides](https://docs.binoban.io/developers/engage).
- **Build retail media experiences.** Sync product catalogs, request ads, and track impressions and clicks with the [retail media integration guides](https://docs.binoban.io/developers/retail-media).

## SDK integrations for web and mobile

| Platform | Repository | What you will find |
| --- | --- | --- |
| Web / TypeScript | [binoban-sdk-web](https://github.com/binoban/binoban-sdk-web) | A typed loader for your deployment's Web SDK, with queued calls during startup. |
| Kotlin / Android / Multiplatform | [binoban-sdk-kotlin](https://github.com/binoban/binoban-sdk-kotlin) | SDK integration guidance for Android and iOS, plus a Compose Multiplatform reference app. |
| iOS / Swift | [binoban-sdk-swift](https://github.com/binoban/binoban-sdk-swift) | A Swift package that distributes the iOS SDK as a prebuilt XCFramework. |

## Seer. Protector. Builder.

Our brand reflects how we approach engineering:

- **Seer: Find the signal.** Turn customer data into understanding, prediction, and insight for informed decisions.
- **Protector: Safeguard the future.** Recognize risks and opportunities early, with governance and control that support trusted decisions.
- **Builder: Put insight to work.** Connect prediction and decisioning to the integrations, customer experiences, and retail media systems organizations build.

## Connect to your environment

Binoban supports private, on-premise, and white-label deployment models. Integration credentials and host URLs depend on your deployment. Follow the configuration guide for your chosen package, or [explore Binoban deployment options](https://binoban.io/deployment).

## Get help and contribute

For bugs and feature requests, use the relevant repository's issue tracker and contribution guide. For deployment access or integration assistance, contact [support@binoban.io](mailto:support@binoban.io).

Report vulnerabilities privately using the repository's security policy or the [organization security policy](https://github.com/binoban/.github/blob/main/SECURITY.md).
